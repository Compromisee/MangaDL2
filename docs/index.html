Why it exists

Built around the awkward parts

Most of the work in a manga downloader is not the downloading. It is everything the sites do to make it difficult.

🔗

Paste any link

The source is detected from the URL, including links with tracking parameters — which used to silently return zero chapters.

🧩

Hostile page layouts

Base64 page arrays, decoy search endpoints, obfuscated readers and randomly named JS variables — each handled per-source.

🖼️

Hotlink-protected art

Covers that 403 without the right referrer are fetched server-side and inlined, so they show up instead of a blank tile.

⚡

Several at once

Queue multiple manga and download them in parallel. Every progress event is tagged, so two series never mix chapters.

🛟

Survives interruption

Chapter-level checkpoints, atomic writes and a resume command, so a crash costs you the current chapter and nothing else.

🎛️

Filters that work

Type, status, genre and chapter-count filters — with unknown values kept rather than silently erasing whole sources.

Three ways in

Pick the interface that suits the moment

Command line

Syntax

Enough flags to script it, short enough to remember.

Basics

# every chapter into one CBZ
$ mangadl https://mangadex.org/title/<uuid>

# chapters 1-50 as a PDF, and an EPUB alongside it
$ mangadl <url> -c 1-50 -f pdf --also epub

# one file per 10 chapters, with a custom name
$ mangadl <url> --per 10 --name-range "{title} Vol {start}-{end}"

# pick up where an interrupted run stopped
$ mangadl resume

Selections

-c all · 5 · 1-20 · 1,5,10-20 · 50- · latest · first

Finding things

# no query at all -> trending across every source
$ mangadl search

$ mangadl search "one piece"                # all sources
$ mangadl search "berserk" -s mangadex     # just one
$ mangadl trending horror                # top horror now
$ mangadl genres                         # every genre

Narrow and sort

$ mangadl search "solo" --type manhwa      # manga|manhwa|manhua
$ mangadl search "one piece" --status Ongoing
$ mangadl search "naruto" -n 5 --sort title
$ mangadl search "berserk" --sort chapters --reverse

For pipes and scripts

$ mangadl search "blue" --urls            # one URL per line
$ mangadl search "blue" --json | jq '.[].title'

# act on a numbered result, no copy-paste
$ mangadl search "berserk" --open 1
$ mangadl search "berserk" --download 1

Interactive menu

$ mangadl menu

  1  Search for a manga     by title, across every source
  2  Browse trending        optionally by genre
  3  Open a URL             paste a link
  4  Library                what you already have
  5  Bookmarks
  6  Settings               folders, formats, sources
  7  Tools                  stats, history, disk usage

  b = back    q = quit    (from any depth)
No extra install. The menu only needs what MangaDL already depends on. The full-screen mangadl tui needs Textual — pip install mangadl[tui] — and says so plainly if it is missing.

Keeping track

$ mangadl watch add <url>     # track for new chapters
$ mangadl watch check         # check them all in parallel
$ mangadl library verify      # do the files still exist?
$ mangadl library scan ~/Manga # re-link a moved folder
$ mangadl stats               # download statistics
$ mangadl disk dupes          # byte-identical files

Sources and settings

$ mangadl sources                    # list them
$ mangadl config up mangakatana      # rank it higher
$ mangadl config disable natomanga   # exclude from results
$ mangadl health                     # breaker + cache state
$ mangadl lock set                   # set an app passcode
Everything lives in ~/.mangadl/config.json — app settings and per-source ranking in one file, written atomically under a single lock.

Install

Two lines

$ git clone https://github.com/Compromisee/MDL
$ cd MDL && pip install -e ".[all]"

# then any of
$ mangadl <url>      # download
$ mangadl menu       # interactive
$ mangadl gui        # desktop app
Python 3.9+. The base install covers the CLI and the menu; [all] adds the desktop app and the full-screen TUI.
