README.md

MangaDL

python3.9+ version1.4.0 tests302 passing sources7 licenseMIT

Download manga from MangaDex, Mangakatana, Natomanga, Weeb Central, Omega Scans, ManhwaRead and Manhwa18 as CBZ, PDF or EPUB — from a desktop GUI, a full-screen terminal UI, or a scriptable CLI. All three share one engine, one library and one settings store.

Install

git clone https://github.com/Compromisee/WeebDL.git && cd WeebDL
pip install -e ".[all]"

Quick start

# download everything as one CBZ
$ mangadl https://mangadex.org/title/<uuid>

# no query? press search anyway — you get trending
$ mangadl search

# browse a genre across every source
$ mangadl trending horror

# the desktop app
$ mangadl gui
Note — MangaDex covers are resolved in three sizes and the thumbnail suffix is appended after the complete filename (abc.png.512.jpg). Dropping the original extension returns a 404, which is the usual cause of missing MangaDex artwork.

What it does

  • 7 sources, one tool — the right one is detected from any URL you paste.
  • Trending on an empty search — the app opens on a discovery feed, not a blank page.
  • Genre browsing — 99 genres merged across sites, ranked by how widely they are supported.
  • Rank and exclude sources — drag them into order, or switch one off entirely.
  • Robust by design — a circuit breaker skips sites that are down instead of waiting on timeouts.
  • Passcode lock — PBKDF2-hashed, with auto-lock and a one-time recovery key.
  • Track what you read — per-chapter progress, watchlists, ratings and notes.

FEATURES.md

Discovery

  • Pressing Search with an empty box shows trending instead of doing nothing
  • Genre browsing and genre-filtered search on every source
  • Quick-pick genre chips, Load more paging, type-ahead suggestions from history
  • Trending interleaves sources so the first screen is a mix

Reliability

  • Circuit breaker per source, with half-open probing and escalating cooldown
  • Bounded retries with exponential backoff and jitter
  • TTL caches for listings and genres — repeat browsing is instant
  • Partial results always win: one dead site never breaks a search

Library

  • Read progress, watchlists with parallel update checks, ratings and notes
  • Statistics, content filters, collections and a persistent download queue
  • Import/export as JSON, CSV or Markdown, plus restorable snapshots
  • Disk usage, SHA-256 duplicate scanning and orphan detection

Interface

  • Six themes, six accents, custom themed dropdowns with type-to-filter
  • Skeleton loaders, fade-in covers, actionable empty and error states
  • Optional passcode lock with auto-lock and cover blurring
  • Reduced-motion preferences respected throughout

Command line

Downloading

# all chapters into a single CBZ
$ mangadl https://mangadex.org/title/<uuid>

# one CBZ per 10 chapters, with a custom name
$ mangadl <url> --per 10 --name-range "{title} Vol {start}-{end}"

# chapters 1-50 as a PDF, and an EPUB too
$ mangadl <url> -c 1-50 -f pdf --also epub

Discovery

# no query at all -> trending across every source
$ mangadl search

$ mangadl trending horror        # top horror right now
$ mangadl genres                 # every genre and who offers it
$ mangadl search "blue" -g Romance

Sources

$ mangadl sources                       # list them
$ mangadl config up mangakatana         # rank it higher
$ mangadl config disable natomanga      # exclude from results
$ mangadl health                        # breaker + cache state

Library

$ mangadl watch add <url>    # track for new chapters
$ mangadl watch check        # check them all in parallel
$ mangadl stats              # download statistics
$ mangadl disk dupes         # find byte-identical files
$ mangadl lock set           # set an app passcode

Adding a source

Sources are plugins. Drop a file in mangadl/sources/ and add one line to the registry — the CLI, GUI and TUI all pick it up automatically.

from .base import Source

class MySource(Source):
    id = "mysite"
    name = "My Site"
    base_url = "https://mysite.com"
    domains = ("mysite.com",)

    def search(self, query, limit=32, **filters): ...
    def get_manga_info(self, url): ...
    def get_chapters(self, url): ...        # oldest first
    def get_chapter_images(self, chapter): ...

Retries, backoff, rate-limit handling, the circuit breaker and atomic image writes all come from the base class.

Why not Comick? It was evaluated and left out: its md_images array returns empty for every title and request variant tested, so chapter pages cannot be resolved. Natomanga was added instead. If that endpoint reopens, Comick drops in as one new module.
